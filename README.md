# XBZ Prime TV WEB 📺

XBZ Prime TV is a premium, high-performance IPTV web application designed to provide a seamless streaming experience. It supports multiple M3U playlist sources, category-based channel filtering, and a responsive app-like interface for all devices.

## 🚀 Features

- **Multi-Source Support:** Automatically merges channels from multiple M3U playlists.
- **Category Filtering:** Automatically organizes channels into groups (Sports, Movies, News, etc.).
- **App-Like Interface:** Mobile-responsive design with a bottom navigation bar for a native app feel.
- **Premium UI:** Sleek, dark-themed interface with hover effects and smooth transitions.
- **Integrated Player:** High-quality HLS streaming support.
- **Easy Deployment:** Optimized for platforms like Vercel and GitHub Pages.

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Streaming:** Hls.js
- **Styling:** Custom CSS with Glassmorphism effects
- **Icons:** Font Awesome

## 💻 How to Deploy

1. Clone this repository to your local machine.
2. Update the `M3U_URLS` array in `script.js` with your desired playlist links.
3. Push the changes to your GitHub repository.
4. Deploy using [Vercel](https://vercel.com/) or [Netlify](https://www.netlify.com/) for the best performance.
