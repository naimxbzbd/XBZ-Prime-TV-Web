# ✨ About

**XBZ Prime TV** is a premium IPTV web application built with **HTML5, CSS3, and JavaScript** that delivers a beautiful, high-performance streaming experience across desktop and mobile devices.

The application automatically merges multiple M3U playlists, categorizes channels, supports HLS streaming, and provides a modern app-like interface with smooth animations and a premium glassmorphism design.

# 📡 Default Playlist Sources

XBZ Prime TV loads IPTV channels from the following playlists by default:

```javascript id="h5v4g8"
const M3U_URLS = [
    'https://raw.githubusercontent.com/naimxbzbd/XBZ-Prime-TV/main/playlist.m3u',
    'https://raw.githubusercontent.com/naimxbzbd/XBZ-Prime-TV/main/BDIXplaylist.m3u'
];
```

You can easily add or remove playlist sources by editing the `M3U_URLS` array inside **script.js**.

Clone the repository

